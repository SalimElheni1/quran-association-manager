# Manual test campaign — 1.4.0-beta.1

- `test-guide-1.4.0-beta.1.docx` — **the guide for testers** (Arabic, read-only). How to test and
  report results (on WhatsApp to the coordinator), the 13 areas to hand out, and the 139 tests
  with their steps and expected results, one area per section. Share it as a view-only Google
  Drive link, as a PDF, or printed.
- `test-plan-1.4.0-beta.1.xlsx` — optional, for the coordinator only: the same tests as a
  spreadsheet with status columns and automatic progress, to note the results testers send.

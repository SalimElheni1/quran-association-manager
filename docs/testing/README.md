# Manual test campaign

`test-plan-1.4.0-beta.1.xlsx` is the test plan and tracker for volunteer testers (Arabic):
139 tests in 13 areas that testers claim, bug reports, testers and an automatic progress tab.

To share it: upload it to Google Drive, open it, then **File → Save as Google Sheets**, and
share the Google Sheet with "Anyone with the link → Editor".
